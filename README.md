# Thesis: Reddit discourse around major AI events

CS 4490Z thesis project comparing Reddit discussion before, immediately after, and one year after three AI events: AlphaGo vs Lee Sedol (March 2016), the ChatGPT launch (November 30, 2022) and DeepSeek-R1 (January 20, 2025).

## Contents

- [data/SUMMARY.md](data/SUMMARY.md): volume estimate per event, window and subreddit, keywords, and scope questions
- [data/README.md](data/README.md): what each data file holds and the filtering-rule log
- [data/ai-use-log.md](data/ai-use-log.md): log of generative-AI use, as the course requires
- [planning/event-corpus-plan.md](planning/event-corpus-plan.md): subreddits, time windows, keywords and confounds
- `data/scripts/`: counting scripts for the Arctic Shift Reddit archive
